# Themes

`survey-ledger.toml` and `survey-night.toml` are this project's own (the page's
default look).

The other 27 are copied unchanged from
[panefx](https://github.com/0p3nMike/panefx) (`assets/themes/`, MIT, © 0p3nMike),
which credits them as follows. Each palette is still its designers' work.

The page also offers any theme you keep in `%USERPROFILE%\.config\panefx\themes\`,
and "Follow panefx" uses the theme panefx has applied (`theme =` in
`%USERPROFILE%\.config\panefx\config.toml`).
